\section{Methodology}

The proposed grading model is based on a fuzzy inference system that integrates multiple variables relevant to continuous assessment in remote or hybrid environments. The methodology consists of three main stages: (1) identification of linguistic variables, (2) definition of fuzzy rules, and (3) implementation and validation of the system.

\subsection{Linguistic Variables}
The model considers both quantitative and qualitative variables, such as participation, assignment submission, self-assessment, and peer evaluation. Each variable is represented by linguistic terms (e.g., low, medium, high) and associated membership functions \cite{Santos2022, Wang2023}.

\subsection{Fuzzy Rules}
Expert knowledge from educators is encoded into a set of fuzzy rules that describe how the input variables combine to produce a final grade. The rules are designed to reflect pedagogical priorities, such as rewarding active participation and consistent effort \cite{Lopez2021}.

\subsection{Implementation and Validation}
The fuzzy system is implemented using MATLAB and Python, allowing for simulation and real-world application. Validation is performed through case studies and comparison with traditional grading methods, demonstrating improved fairness and support for meaningful learning \cite{Nguyen2020, Smith2023}.
